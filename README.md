## Использование в RS School

Студент может использовать материалы для изучения темы и самопроверки. Ментор — ссылаться на нужные объяснения и примеры в обратной связи студенту.

Требования определяет конкретное задание, а порядок ревью и оценки — [документация школы](https://github.com/rolling-scopes-school/docs/blob/master/docs/ru/mentoring/pull-request-review-process.md). Справочник объясняет практики и их применимость. Чеклист не является самостоятельной шкалой штрафов.

Для каждого замечания полезно указать место в коде, последствие и способ проверить исправление. Подробность объяснения и объём рекомендаций можно адаптировать к студенту, сохраняя одинаковые критерии задания.

Все учебные материалы хранятся в одном месте — `clean-code/`. Для чтения достаточно открыть Markdown-файлы на GitHub или локально.

## Как внести вклад

Исправления ошибок, уточнения и примеры из практики приветствуются. Порядок работы и требования к материалам описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
