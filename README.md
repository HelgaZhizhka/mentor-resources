### Автоматизация проверки кода для менторов

Автоматизация — это инструмент, а не замена ментора. Цель — сократить время на рутинные проверки, чтобы у ментора было больше времени на качественный и глубокий фидбек по архитектуре, подходу к задаче и soft skills студента.

**Что даёт автоматизация:**

- **Экономия времени:** базовые проверки за 1-2 минуты вместо 10-15
- **Фокус на важном:** ментор сосредотачивается на архитектуре и бизнес-логике, а не на подсчёте интерфейсов
- **Готовая структура:** детальный отчёт для студента с конкретными примерами

#### Инструменты автоматизации

**1. Скрипт автоматической проверки** → [`auto-check.sh`](./templates/scripts/auto-check.sh)

Проверяет технические аспекты проекта:

- TypeScript конфигурация (strict mode, noImplicitAny)
- ESLint настройки и количество ошибок
- Использование TypeScript features (interfaces, generics, enums, classes)
- Качество кода (console.log, закомментированный код, TODO)
- Git коммиты (conventional commits формат)
- Сборка проекта без ошибок

**2. AI агент для code review** → [`reviewer.md`](./templates/agents/reviewer.md)

Проводит детальный анализ кода на основе файлов репозитория:

- Clean Code принципы (именование, размер функций, DRY, KISS)
- TypeScript/React best practices
- HTML/CSS/UI-UX качество

Агент создаёт детальный отчёт с примерами кода и рекомендациями.

**3. ESLint конфигурация** → [Подробнее](./templates/configs/LINTER-README.md)

Покрывает базовые правила автоматически:

- ✅ TypeScript строгость (no any, явные типы)
- ✅ Чистые функции (длина ≤30 строк, ≤3 параметра)
- ✅ React best practices (hooks, keys, exports)
- ✅ Async/await правила
- ✅ Мёртвый код и console.log

**4. Чек-листы для проверки** → [`templates/checklists/`](./templates/checklists/)

Структурированные списки критериев для разных типов заданий.

#### Кастомизация под себя

Все инструменты можно адаптировать под свои нужды:

- **Скрипт:** добавить клонирование репозитория, изменить критерии проверки, добавить новые метрики
- **AI агент:** настроить промпт под специфику задания, добавить свои критерии оценки
- **ESLint:** изменить правила под требования
- **Чек-листы:** создать свои под конкретные задания
